理解算法

每一种步伐，都有来由。

梯度告诉方向，优化器决定怎么走。

SGD

只看眼前的坡度
wₜ = wₜ₋₁ − ηgₜ

直接朝负梯度走一步。坡越陡，步子越大；学习率过大时，也更容易跨过谷底。

本实验使用完整解析梯度，没有随机采样噪声。

Momentum

记住刚才的方向
vₜ = μvₜ₋₁ + gₜ
wₜ = wₜ₋₁ − ηvₜ

把历史梯度累积成速度。惯性能帮助持续前进，也可能带来过冲、震荡，甚至跨入另一片盆地。

经典 Momentum，未启用 Nesterov。

Adam

记方向，也记尺度
mₜ = β₁mₜ₋₁ + (1−β₁)gₜ
wₜ = wₜ₋₁ − ηm̂ₜ / (√v̂ₜ + ε)

结合梯度的一阶、二阶矩与偏差校正，逐坐标调整有效步幅。稳健的步子不一定在这里最先到达。

vₜ 为 gₜ² 的指数平均；帽号表示偏差校正。

RMSprop

为陡峭方向缩小步幅
sₜ = αsₜ₋₁ + (1−α)gₜ²
wₜ = wₜ₋₁ − ηgₜ / (√sₜ + ε)

用近期梯度的平方平均归一化每个方向。它能缓解尺度差异，也可能在靠近谷底时持续小幅摆动。

非中心化 RMSprop，未叠加额外动量。

计算约定与可复现性

曲面使用 [−5,5]² 上的 121 × 121 网格。记录 t=0 起点与每次更新后的坐标和原始损失。显示的高度变换不会改变计算结果。路径只在渲染时微小抬升以避免被曲面遮挡；导出数据没有抬升。二维损失图将小于 10⁻¹⁶ 的值绘制在 10⁻¹⁶，真实数值保留在表格与导出文件中。

路径不裁剪到曲面边界。如果下一次更新产生非有限值或损失超过 10¹²，则停止对应优化器，并保留有效记录。最近谷底只是距离判断，不代表收敛。若暂停回放，记录表与文字结论仅基于截至当前步的路径，导出文件仍包含完整实验。

以 w₀ 为起点，第 t 次更新使用 gₜ = ∇L(wₜ₋₁)，t ≥ 1。所有平方、除法和平方根逐坐标执行。Adam 的二阶矩更新为 vₜ = β₂vₜ₋₁ + (1−β₂)gₜ²，m̂ₜ = mₜ/(1−β₁ᵗ)，v̂ₜ = vₜ/(1−β₂ᵗ)。ε = 10⁻⁸。

谷底放大使用新的局部 121 × 121 网格，自动调整坐标和高度范围。三维线段在相邻更新间沿参数直线细分，并按函数值绘制在曲面上；局部视域会补入边界交点并加密连接，避免短路径被隐藏。悬浮放大窗重新采样局部 49 × 49 曲面，以独立的侧面透视展示坡面和路径。插值不参与优化，导出仍保留原始记录。
