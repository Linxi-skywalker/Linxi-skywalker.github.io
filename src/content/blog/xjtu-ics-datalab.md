## twin: 返回最小补码
首先：补码的表示即最高位为负权重，其余为正权重，容易知道最小补码即最高位为1,其余均为0,那么即可利用左移操作`1<<31`构造出最小补码

## upperBits: 将高n位填充为1
根据要求：我们需要构造一个这样的数：前n位都是1,后面其余位均为0,于是我们想到只需要先构造一个全为1的数字，然后将他末尾n位1保留，其余1删除，再继续在保留的n位1后补0即可实现操作
那么如何构造全为1的数字：最简单的方式就是对0取反，`～0`
如何只保留末尾n位0并继续在保留的n位1后补0呢：可以通过左移操作，将原来全为1的数字左移`32-n`位
但是题目要求不能使用 `-`，我们可以用加相反数实现减法的操作：`32-n`-->`32+(~n+1)`

但是，如果留意边界条件会发现0则需要移动32位，这是未定义的操作，不被允许移动32位，因此我们需要分类讨论“
当n=0时返回0；n！=0时则返回`（～0）<<32+(~n+1)`，那么怎么实现呢：
事实上我们发现一个数字m如果与全为1的数字做与操作&，还会得到其本身，如果与全为0的数字进行与操作，则会得到0，
利用这一特性，我们可以这样处理结果：
构造这样的表达式：`！n+～0`：这样n为0得到0,n非0得到全为1的数

最后结果就可以这样表达：`((~0)<<(32+(~n+1)))&(!n+~0)`

## sign: 正数返回1,负数返回-1
首先我们只考虑正负数，判断正负数只需要判断最高位是0还是1即可，那么我们可以通过右移（而本实验中默认为算术右移）来保留符号位，即令 `m=x>>31`，这样如果是正数，m二进制为全0（0）,负数时m二进制为全1（-1）。而我们想得到正数时输出1,负数时输出-1,只需要让正数时结果再加1,负数时结果加0即可满足条件：
于是我们只要让结果变为 `m+！m`就能符合这样的条件
最后我们处理0的情况，事实上和上一题一样，只需要`&(!x+~0)`就能实现x为0时结果为0,x不为0时结果为 `m+!m`,即正数为1,负数为-1,

最终表达式为：`(m+(!m))&((!x)+~0)`  其中 `m=x>>31`

## copyBit:  将结果的所有位设置为x的第n位
根据题意：我们需要提取x的第n位，如果是1,结果就全为1,如果是0,结果则全为0
那么我们可以先将数左移`31-n`位，这样将这个数置于最高位，然后通过右移（算术右移）31位，即可实现最高位的复制
那么表达式就变成 ： `(x<<(31+(~n+1)))>>31`

dlc发现操作符被限制：只允许使用：! ~ & ^ | << >>
但是我们仍然采用同样的思路：先将第n位提取出来，由于不能使用+，因此我们可以通过构造只有第n位为1的数字将第n位和x作与运算`m = x&(1<<n)`，如果结果是不为0,第n位则为1,反之为0,于是接下来我们只需要将这一位复制即可：首先对m进行两次！操作将结果控制在只有0,1；然后对其先进行左移再算术右移即可得到答案
最终表达式：`(!!m)<<31)>>31`，其中：`m = x&(1<<n)`


## fitsBits: 若x可表示为n位补码整数则返回1,否则返回0
首先我们需要理解什么叫做x可以表示为n位补码整数：用n位补码表示时，最高位需要作为符号位为负权重，那么将n位补码补全为32位时，前面需要填充之前最高位的数字，这样就可以用32位表示同一个数字，因此如果一个数x可以表示为n位补码整数时，先将n位补全为32位，再进行截断仍为之前的数字，反之如果不能表示，先进行补全，再进行截断会使得符号位丢失从而不等于i之前的数字。
这样我们就可以先将数左移`32-n`位，这样将这n位置于最高位，然后通过右移（算术右移）`32-n`位，然后与之前的数字进行比较，相同则可以表示，输出1,反之输出0；
怎么比较两次的数字是否相同呢，我们采用异或操作，如果结果为0则相同，结果不为0则不同，而我们需要输出的是：相同输出1,不同输出0,于是我们在进行一个！操作，就完美解决这一问题，若相同输出1,不同输出0；
表达式为 `!(y^x)`          其中  `m=32+(~n+1)`  ; `y=x<<m>>m`

## anyOddBit: 若字中任意奇数编号的位被置为1返回1
根据题意，我们容易想到只需要提取奇数编号数字，对奇数编号数字进行一个与操作，如果结果为0,显然奇数编号没有1,相反地，结果不为0则说明有1,需要返回1
那么我们可以通过构造这样一个数 `10101010...`，然后与之前的数字与即可
而由于题目限制我们只能直接采用0-255的数字，因此我们可以通过对0xAA不断左移并与原数取|，即可延长0xAA
最终表达式为： `!!(x&n);`，其中：`n = (m<<16)|m;`  `(0xAA<<8)|0xAA;`

## distinctNegation: 若x！=-x，则返回1,否则返回0
根据题目含义，直接返回`!!(x^(~x+1))`即可
## isGreater: 若x>y,则返回1,否则返回0
我们容易想到直接算x-y，如果大于0返回1,否则返回0；但实际上这样会出现溢出，于是我们需要进行对x，y正负的讨论，如果正负数进行比较结果显而易见，而如果是同符号进行比较那么我们再进行计算x-y这样也不会产生溢出

```
int m = x>>31;
int n = y>>31;
int u = m^n;
int v = x+(~y+1);
return !!(u&(~m))|((~u)&((v>>31)+1)&((!v)+~0));
```
## isAbsEqual: 若绝对值相等返回1,否则返回0
首先我们想到绝对值相等无非只有两种情况，要么x=y，要么x=-y，当然也存在两者同时满足的情况，由于只能使用!,^,+，很难在有限操作符内构造出-或者～，因此需要用x+y=0来判断x是否等于-y，而x是否等于y则可以通过x^ y是否等于0来判断，这样一来我们可以用`!(x^y)`和`!(x+y)`来表示两种情况，容易发现只要有一个结果为1,那么返回1就可以满足要求，于是我们将两种情况的结果加起来，并通过两次！！控制结果为0和1,两种，当两种情况均不满足时最终结果显然为0,而只要满足一组或者同时满足最终结果都为1,直接输出即可

因此，最终表达式为： `!!(((!(x^y))+(!(x+y))))`
## howManyBits: 返回用补码表示x所需的最小位数
首先我们理解什么叫做用补码表示x所需的最小位数，通过几个例子我们能够发现其实就是找到x的最高有效位，正数加上符号位即可
由于正负数补码的区别，负数前面是一串一，且不需要额外加上符号位，我们希望统一正负数，最终变成同一种方式，于是我们只需要将负数转化为其正数形式：我们将正数与0作异或，负数与-1作异或，这样即可统一两种形式，问题就变成了找到最高位的1然后加上1既可以满足要求：
这里由于提供有32位，而运算符限制在90个，我们很难通过遍历每一位的方式解决，于是我们采用一种非常优雅的方式解决：二分

先看高16位，将转化后的数字右移16位，如果结果为0说明高16位没有1,反之则说明有，于是我们不断二分进行查找，然后16（0）+8（0）+4（0）+....+1(0)+最后剩下的一位数+符号位即可确定所需最小位数

表达式如下：


```
int howManyBits(int x) {
int m;
int n;
int u;
int v;
int w;
int d;
m = (x>>31)^x;
n = !!(m>>16)<<4;
m >>= n;
u = !!(m>>8)<<3;
m >>= u;
v = !!(m>>4)<<2;
m >>= v;
w = !!(m>>2)<<1;
m >>= w;
d = !!(m>>1);
m >>= d；
return n+u+v+w+d+m+1;

}
```
